# Notebooks

Folder ini digunakan untuk eksplorasi data dan prototipe model sebelum
diimplementasikan ke `backend/app/engines/`.

Rencana isi:

- `01_eksplorasi_data_pasang_surut.ipynb`
- `02_eksplorasi_curah_hujan.ipynb`
- `03_prototipe_indeks_rob.ipynb`
- `04_validasi_terhadap_historical_events.ipynb`
- `05_eksperimen_model_ml_tahap3.ipynb` (Random Forest, XGBoost, LSTM)

Gunakan `poetry`/`venv` terpisah atau environment yang sama dengan backend
(`backend/requirements.txt`) agar konsisten dengan dependensi produksi.
