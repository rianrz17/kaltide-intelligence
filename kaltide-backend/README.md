# KALTIDE Intelligence Backend

Backend API untuk Kalimantan Tidal Flood Intelligence System. 
Dibangun menggunakan Python dan FastAPI untuk fase MVP (Balikpapan, PPU, Kukar).

## Cara Menjalankan Lokal
1. Install dependensi: `pip install -r requirements.txt`
2. Jalankan server: `uvicorn main:app --reload`
3. Buka dokumentasi API di: `http://127.0.0.1:8000/docs`
